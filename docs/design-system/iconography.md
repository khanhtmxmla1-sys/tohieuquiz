# TôHiệuQuiz Iconography

## Ba tầng icon

1. Icon thao tác nhanh hiện tại: giữ nguyên tại dashboard giáo viên.
2. Icon module: ảnh thương hiệu 40–80px cho tiêu đề, card, empty state và onboarding.
3. Lucide: icon thao tác 16–20px cho sidebar, sửa, xóa, đóng, tìm kiếm, lọc và bảng.

## Kích thước

- `sm` 40px: card chức năng.
- `md` 48px: tiêu đề module.
- `lg` 64px: empty state.
- `xl` 80px: onboarding hoặc giới thiệu.

## Chưa gắn production

- `competition`: chưa có module Cuộc thi độc lập; không dùng thay Thi trực tiếp hoặc Thành tích.
- `system-settings`: chưa có module Cài đặt hệ thống độc lập; không đặt vào Cài đặt cá nhân.
